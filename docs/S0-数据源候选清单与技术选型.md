## 一、技术选型：轻量闭环（零第三方依赖）

| 项 | 选型 | 理由 |
|---|---|---|
| 运行时 | Python 3.12.10（本机 `D:\dev\py312\python.exe`，已在 PATH） | 已装，无需下载 |
| Web / SSE | 标准库 `http.server.ThreadingHTTPServer` | 免装 Flask/FastAPI |
| 存储 | 标准库 `sqlite3`，WAL 模式 | 免装数据库 |
| 事件总线 | SQLite `events` 表（自增 seq 作为有序日志）+ 进程内 `queue.Queue` 分发 | **不装 Redis / NATS**；SQLite 单文件即可满足「有序 + 可重放 + 可 ACK」 |
| 窗口计算 | 自实现 event_time 滑动窗口 + 水位线（watermark） | 不引入 Flink / RisingWave |
| HTTP 采集 | 标准库 `urllib.request` | 免装 requests |
| 前端 | 单文件 HTML + 原生 JS + EventSource | 无构建工具、无 npm |
| 第三方依赖总数 | **0** | 一键启动只需 `python app.py` |

**未选用重型框架**：Flink / Spark / Kafka / RisingWave / ksqlDB 全部排除，符合硬性约束 1。

**为什么不用 Redis Streams**：需要额外安装服务、占端口、Windows 上还得跑 WSL 或 Docker。SQLite 表 + 自增 seq 已能提供「有序、可重放、消费位点可持久化（ACK）」，且回放天然支持按时间区间查询——这正是验收标准第 4 条要的。

### 条款与频率的诚实声明

- **我没有逐条阅读上述站点的使用条款**。表中「频率与条款」列是我依据接口形态给出的**保守建议值**，不是官方配额。正式启用前请你确认各站 ToS，尤其是 A1–A4 这类非官方行情接口。
- 所有采集器都会实现**自适应限速 + 指数退避**，默认间隔写入配置文件，可改。
- 不绕过反爬、不伪造登录态、不抓取需登录内容。A1 需 `Referer` 头是接口自身的防盗链要求，属正常调用。

### 关于「实时性」的定义

A 股等证券的免费公开源**不承诺毫秒级实时**。本系统把实时性定义为「**数据源允许的最小刷新间隔**」，并在界面常驻显示：

- 每个数据源的最后成功时间
- 端到端延迟（event_time → 入库 → 规则命中 → SSE 送达）
- 当前数据模式（LIVE / 回放 REPLAY），回放时显著标注
